# Design rules

Source: LUME_PRD.md §9–10.

- Visual keywords to hit: luxury, editorial, minimal, organic, scientific, soft technology, premium hospitality.
- Explicitly avoid: generic hospital aesthetics, heavy blue medical UI, cheap gradients, generic stock imagery, dashboard-like cards, excessive rounded containers.
- Typography: strong display face paired with a clean UI/body face; contrast editorial headlines against modern UI text. Arabic typography must complement the Latin system, not just substitute a font.
- Use `frontend-design` skill for aesthetic direction and typography decisions — don't default to generic component patterns.
- Use `impeccable` skill for polish/critique passes before calling a section done.
- All colors, type scale, spacing, radii come from the Tailwind theme config — no inline magic values.
