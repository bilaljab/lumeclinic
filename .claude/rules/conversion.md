# Conversion rules

Source: LUME_PRD.md §3, §7.

- Booking CTA ("Book Consultation") must stay reachable throughout the page: persistent in the desktop navbar, sticky bottom bar on mobile.
- WhatsApp is the secondary conversion path and must always stay easy to access. Prefill the message contextually (treatment-specific, doctor-specific) where the trigger point makes that possible.
- Use the `cro` skill for any conversion-critical section: hero CTAs, treatment explorer, packages, final CTA, booking form.
- Every section should nudge the visitor toward Discover → Desire → Explore → Trust → Consider → Book (PRD §5) — don't add content that dead-ends the journey without a next step.
- Trust/testimonial content stays visually restrained — this is not a discount/coupon site, avoid aggressive urgency patterns (countdown timers, fake scarcity).
